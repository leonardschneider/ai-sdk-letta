An AI SDK `LanguageModel` for Letta agents over the Letta Agent SDK (cloud, local and self-hosted app servers); an unofficial, MIT-licensed port of Letta's `@letta-ai/vercel-ai-sdk-provider`. The fork's earlier "2.0.0" was never published as `@ai-sdk-letta/provider`; see the history below.
