Agent settings page: clicking an agent in the Agents section, or its name in the breadcrumb (`agent > Settings`), opens its settings in the main area in place of the conversation (`#/agents/<id>/settings`, so a reload keeps it; "Back to conversation", Escape or picking a conversation closes it, "Open chat" opens the agent's chat). One scrollable page with a table of contents (stacked on phones): **General** (name, model and reasoning, changed inline for adopted agents or "Set in code" for the app's own agent, View only), **Tools** (tool sets, project folder, command time limit), **Instructions** (status, Preview diff, Apply, Revert), **Apps** (status, Restart, Stop, Logs, "Allow always" grants and Reset, the dev-app "without asking" toggle), **Memory** (reviewer model, review history), **Automations** (tokens), **Members** (team admins) and **Danger zone** (Remove from app); sections that don't apply to the agent are hidden. The dialogs are now thin wrappers around the same panels and stay reachable from the sidebar footer and the ⋯ menu, which gains "Settings". Single-agent setups get a Settings row in the sidebar footer.
